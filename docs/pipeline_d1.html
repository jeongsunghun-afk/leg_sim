D1 (OCS2 NMPC) 파이프라인 & A·B·C·D1 비교

D1 = NavBotHub 계열 legged_control(OCS2 센트로이달 NMPC 100 Hz + 계층 WBC HoQp 1 kHz) → AMP 데이터 → HIMLoco RL → 배포. A(우리 배포 SRBD-MPC+WBIC)와 구조가 동일한 2단이고, 차이는 NMPC(kino-dynamic) vs 볼록 SRBD뿐.

⚠️ D1은 우리가 분석만 한 외부 생태계(NavBotHub/qiayuanl legged_control·D1_rl_sar). 미구축·공통벤치 없음 → 성능 우열 현재 판단 불가. 이 문서는 구조 대조·아키텍처 위치 확인용. 상세=메모리 d1-navbothub-mpc-amp-analysis.

D1은 단일 컨트롤러가 아니라 MPC교사→RL증류→배포 파이프라인이다. 우리 하이브리드 로드맵의 실전 청사진.

OCS2 모델·솔버 요점

FullCentroidalDynamics : ẋ = f(관성텐서(q)·중심운동량 + 관절kinematics) — SRBD보다 고정밀(관성이 자세의존)
SLQ / SQP(Multiple-Shooting) + HPIPM · 연속시간 최적제어 · 실시간 반복(RTI)

HoQp = null-space 계층 QP(엄격 우선순위). 우리 A의 WBIC(가중 QP)·B의 TSID와 같은 계열, 계층화가 더 엄격.

A와의 유일한 실질 차이 = MPC 모델: A는 볼록 SRBD(관성 고정, QP 초고속 1 kHz) · D1은 비볼록 센트로이달 NMPC(관성 자세의존, SLQ 100 Hz). 나머지(2단·WBC·접촉)는 동형. → D1 구축은 A/B와 정보 중복이 우리 판단(B가 이미 kino-dynamic 자리).

4 · 핵심 결론 왜 D1 미구축·어디에 위치

  • A·D1은 같은 2단 구조(MPC+WBC). 차이는 SRBD(A) vs 센트로이달 NMPC(D1)뿐 → D1 구축은 A(배포)+B(이미 kino-dynamic)와 정보 중복, 한계효용 낮음.
  • D1의 진짜 값어치 = AMP→RL 파이프라인(MPC교사→robust RL). 이건 우리 RL 하이브리드 피벗의 실전 청사진이고, D1 MPC 없이도 우리 A/B·TOWR·브리지를 교사로 재현 가능.
  • 지형계획 상한 조사 결론(별도): 모델기반 폐루프(A footScore·B heightmap)는 연속+구조화 지형 소유, robust 불연속은 RL. TOWR=오프라인 최적 참조/교사. → TOWR·모델기반 지형 리포트.
