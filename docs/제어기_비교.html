  • 연속지형 = 모델기반(A·D1) 강함: A는 경사·균일계단(H≤~0.06)을 반응형으로 등반, D1(perceptive NMPC)은 지형적응 base높이로 blind를 낙상 5~7× 압도(15°램프 z→0.84). = A·D1의 배포가치.

3포지셔닝 각 제어기의 역할

  • A 본선 배포 — 1kHz 실시간, GUI 전기능 조종. 평지·중속·선회·기립. 연속지형 반응형.
  • B 연구·TOWR 소비자 — 비실시간(~14 Hz). TOWR 궤적을 TSID로 추종(towr_track_B.py)했으나 B 자체 ~3.3s 낙상(안정화 미완)이라 그 위 TAMOLS는 블록. TAMOLS+B는 B 안정화 선행 필요.
  • C 연구·풀동역학 베이스라인 — 평지 전용, 지형 플래너 없음.
  • D1 실시간 모델기반 포팅(진행) — OCS2 legged_robot을 02_Leg MuJoCo로 포팅. 동적 TROT 0.3~0.7 m/s falls=0·16-DOF 능동발목·perceptive SDF Phase3a 작동. 통합 폐루프 NMPC로 injection 마진 근본해결 목표. 단 perceptive 핵심(발판배치·지형base)은 Phase3b 브리지 통합이 남아 현재는 클리어런스만(턱을 '건너지'는 못함). 외부 legged_control(NavBotHub)은 레퍼런스. 상세 pipeline_d1·D1 리포트.
  • CI 준정적 자세추종은 성공, 동적 보행은 실패 — 성공: 서기·눕기·앉기·A자세캡처 준정적 추종(해석그래디언트 EXACT·foot-slip·DCM 완성). 실패: walk(동적보행)·gap·외란·두발 = 현실접촉서 균형 프론티어 붕괴. → 로버스트 험지 부적합으로 종결(음성결과=RL 방향 근거). 접촉창발 연구niche.
