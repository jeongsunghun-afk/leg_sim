RL 파쿠르 정책 파이프라인 & MPC/OCP 구조 대조

RL 정책은 최적화를 오프라인(PPO 50k iter)에 몰아넣어 네트워크 가중치로 상각(amortize)한다 — 런타임은 값싼 MLP 순전파(forward pass)다. 반면 A(MPC+WBIC)·B·C(OCP)는 매 틱 온라인으로 최적화 문제를 푼다. 그럼에도 셋 다 계획(50 Hz급) → 저수준 추종(≥200 Hz)의 2-레이트 골격을 공유한다.

이 문서의 RL 대상 = 클론한 RobotSW_IsaacLab 포크의 파쿠르 태스크(direct/parkour). 정책=ActorCriticRMA(피드포워드 MLP, 비순환·LSTM 아님) + 지형/이력 인코더 + RMA teacher-student. A/B/C 정의는 pipeline.html(A)·pipeline_bc.html(B·C) 참조.

RL 1 · 파쿠르 정책 파이프라인 Go2 12-DOF · 물리 200 Hz · decimation 4 → 정책 50 Hz

MPC/OCP가 "무거운 계획기 + 가벼운 추종기"를 매 틱 새로 푸는 것과 달리, RL은 그 계획기를 학습된 MLP로 대체한다. 관측→관절 위치 잔차(residual)를 내는 정책을 50 Hz로 추론하고, 고정 게인 PD가 200 Hz로 토크를 만든다.

RL 2 · 정책 구조 — ActorCriticRMA (MLP, 비순환)

LSTM/GRU가 아니다(is_recurrent = False). 시간 맥락은 순환 상태가 아니라 고정 길이 이력(10×42)에 대한 1D-CNN 인코더로 처리한다. rsl_rl 라이브러리에 ActorCriticRecurrent(LSTM/GRU)가 있으나 파쿠르 config는 이를 인스턴스화하지 않는다.

Teacher → Student (RMA)

  • 교사 경로(학습): priv_latent(37) → priv_enc → 20-latent. 특권정보(마찰·질량…)를 직접 봄.
  • 학생 경로(배포): proprio 이력 → CNN → 20-latent. 특권정보 없이 같은 latent를 추론.
  • distillation: priv_reg = ‖priv_latent − hist_latent.detach()‖₂ (스케줄 계수) — 학생을 교사에 회귀.
  • estimator: proprio로 base 선속도 v̂를 추정, 학습 후 실제 priv_explicit을 대체(train_with_estimated_states).

변형(전부 여전히 MLP RMA): MoE(6 experts, gating[128]) · SPO surrogate · LCP gradient penalty · Symmetry 좌우증강 · AMP(모방, discriminator) · Lidar/Voxel(별도 인코더). 순환 정책은 어느 변형에도 없음.

한 줄 요약: RL은 오프라인 학습으로 "계획+지각+게이트"를 하나의 MLP에 상각하고 저수준은 값싼 PD에 맡긴다. MPC/OCP는 매 틱 명시 모델로 최적화를 풀되 대신 지각·게이트를 손으로 설계한다. 하이브리드 전략(MPC_RL_하이브리드_전략_리포트.md)은 이 둘을 결합 — MPC를 교사/안전필터/레퍼런스로 쓰는 5패턴.
