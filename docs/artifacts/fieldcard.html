브링업 — 멈춰야 하는 자리만

전체 29단계는 상세판 §7

  1. 크레인에 매단다. 발이 뜬 상태로. IMU 가 전부 0 → tilt E-stop 무력. 크레인이 유일한 안전장치다.
  2. git pull 뒤엔 반드시 재빌드. cmake --build build --target biped_deploy -j4. 옛 바이너리는 새 명령 필드를 조용히 무시한다 — 측정 하나가 통째로 날아갔다.
  3. biped_emb.py 를 끈다. writer 는 하나만. 배포가 exit 4 로 거부한다.
  4. 기동 배너 + 상태줄 — 하나라도 다르면 중단. cmode · SCHED_FIFO 80 · 트립각 7.16° · 링크eth0 OK(⛔+N 이면 그 세션은 언제 얼어도 이상하지 않다) · 온도 80°C 미만.
  5. home 뒤 실제 자세를 눈으로. 평발이면 밑창 수평계(foot gear_k 1.2/1.60 미해결 — 상태창으론 안 보인다) · 점발이면 float 고각(+27°↑)에서 HL 이 떠오르는지(케이블 기하 — 수리 전 정상 증상).
  6. 하중 이양은 hold 로. stand 는 그 뒤. 접지 판정은 QP 실패율로: 정상 K=4 · ~0% · 발뜸 K≤3 · ~95%. 접촉 부족이면 중력보상 폴백인데 겉보기엔 안정돼 보인다.
  7. 종료는 물리 리셋까지. Ctrl+C 는 Kp=Kd=τ=0 을 쓸 뿐 모터를 끄는 게 아니다. 명령을 끊으면 드라이버는 마지막 명령을 계속 실행한다.
