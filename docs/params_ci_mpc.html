★ CI-MPC walking — hard 접촉 + λ 해석 그래디언트 2026-07-23 논문핵심

파일 ci_mpc_walk.py. 아키텍처(HOUND식): planner soft forward + exact λ 그래디언트 backward · sim=hard 접촉(step_kkt) · 저수준 PD+FF fine rate MPC계획 추종. walking 2.7~3.6s 안정 실증(runaway는 exact λ그래디언트가 소멸).

01 iLQR 코어 MjxDynamics + Riccati

상태 x=[qpos24, qvel23]=47, 제어 u=17. f(x,u)=mjx.step. 선형화 fx,fu ← jax.jacfwd(★forward-mode가 접촉 while_loop 통과, reverse는 막힘).
★접촉 강성: STIFF=0.002 기본(2026-07-22 배포 표준 quad_centroidal 파리티로 동일화). 이전=soft(발 penetrate)라 gap서 mushy push-off→다이빙. STIFF=crisp 물리로 크로싱 개선(STIFF=0로 soft 복귀 가능). soft=최적화 그래디언트 매끈하나 물리 mushy=C-1(hard forward+완화상보성 그래디언트)의 존재 이유.

04 capture-point 착지 2026-07-20 신규

lunge(실제 vx ≫ 명령 VX) 시, 스윙 착지를 명령 VX로 예측하면 앞발이 far platform에 못 미쳐 gap으로 다이빙. Raibert capture-point로 측정 속도에 맞춰 발을 더 앞으로 뻗어 몸통을 잡음.

파라미터값의미

cap (스윙 offset)0.5·(vx_meas − VX)·T_stance★lunge 시 착지를 앞으로 추가 이동(braking reach)
vx_meas 상한0.9clip 상한(폭주 속도에 과반응 방지)
효과. VX=0.3에서 이 항으로 몸통 중심이 gap1(x 0.5–0.55)을 통과(base 0.33→0.67, 크로싱 첫 달성). 단 crossing 직후 잔여 lunge로 낙상 → dynamic throw-and-catch 안정화(착지 후 제동)가 남은 과제.
