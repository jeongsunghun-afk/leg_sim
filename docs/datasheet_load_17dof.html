관절별 토크·각속도 부하 — trot vs walk

보행속도별 각 축의 peak·RMS 사용률. 앞·뒤 다리를 나란히 두어 비교합니다. 실모터 물리(토크-속도곡선 + 기어박스 반사관성 + 속도한계) 하에서 정상구간 측정.

뒤 thigh 폭주 해결 — 발배치(raibert_k)를 표준 중립점으로

원인은 발배치였습니다. Raibert 게인 raibert_k=0.8이 발을 속도비례로 과하게 앞에 던짐 → 지지면이 CoM보다 앞으로 → CoM이 지지면 뒤쪽에 걸림 → 뒷발에 하중 집중(뒤 thigh 접촉토크 폭증). 이를 교과서 Raibert 중립점 raibert_k=0.5(발 위치 = 0.5·v·T_st)로 낮추니 GRF가 앞뒤로 균형을 이루고 뒤 thigh가 절반으로 떨어졌습니다. 외란복구 reach는 KCAP 피드백+MPC가 담당하므로 중립게인을 부풀릴 필요가 없습니다.

peak·RMS 둘 다 peak한계 기준 (비교 가능)

peak% = peak ÷ peak한계(예 84)
RMS%  = RMS ÷ peak한계 ← 같은 분모

모터 발열 ∝ τ² 라 연속(열) 한계는 RMS 기준. 정격 = peak ÷ 3 = peak의 33%(전 관절 공통). 그래서 RMS가 33%를 넘으면 연속정격 초과 ▲(지속 주행 시 과열). peak는 100%가 순간 한계.
