02_Leg · 17-DOF · 모델기반 제2트랙

Contact-Implicit MPC 파이프라인

험지(gap·stepping) 크로싱의 근본 한계인 고정 접촉 스케줄을 넘기 위해, 접촉 모드·발판·타이밍을 온라인으로 동시에 발견하는 CI-MPC를 설계·구현한다. 배포 컨트롤러(A: WBIC+MPC)는 불변이며, 이는 병렬 연구 트랙이다.

스택 Crocoddyl · Pinocchio · MuJoCo/MJX(GPU)  ·  코드 simulation/quad/ci_mpc/  ·  참조 Kim et al. 2023, Contact-Implicit MPC (KAIST HOUND)

01 왜 필요한가 — 고정 스케줄의 벽

타이밍을 결정변수로 못 올리면 지형 간격에 스텝을 맞출 수 없다

현재 컨트롤러 A(WBIC+SRBD MPC)·B(centroidal)·C(fulldynamics)는 모두 접촉 스케줄 (T_ds/T_ss)을 고정 입력으로 두는 fixed-schedule이다. 발 cadence·step length가 지형 간격과 우연히 맞는 gap만 넘는다 — 속도-공명(speed resonance). selectFoot(③)은 발판 위치만 nudge할 뿐 타이밍은 못 바꾼다.

타이밍을 최적화하려면 접촉 on/off가 결정변수가 되어야 하는데, 그러면 문제가 비볼록(이산/상보성)이 되어 실시간 볼록 QP가 깨진다. 이 벽을 넘는 두 갈래 = 모델기반 CI-MPC 또는 RL. 지형 이산 발판 탐색은 RL 피벗을 유지하고, 본 트랙은 접촉 모드 창발을 담당한다.

02 제어기 핵심 구조 HOUND식 CI-MPC

hard 접촉 forward + relaxed 상보성 λ 해석 그래디언트 backward의 분리 + multiple-shooting FDDP + 저수준 PD+FF 추종

입력: desired 몸통 pose 참조(base 미션: 속도/자세/높이) + nominal stance 관절각(고정)
   ┌──── MPC optimizer (receding horizon · multiple-shooting FDDP) ────┐
   │  forward  : 접촉 forward (MuJoCo/Pinocchio 로버스트, dt~2ms)         │
   │  backward : ★λ(접촉임펄스) 해석 그래디언트 ∂λ/∂(q,v,u)          │
   │             = relaxed 상보성(v·λ=ρ, well-conditioned)              │
   │  solver   : gap 주입 backward + feasibility-driven forward + merit  │
   └───────────────────────────┬────────────────────────────────────────┘
                        계획 (q_plan, v_plan, u_ff)
   ┌───────────────────────────▼────────────────────────────────────────┐
   │  저수준 (HOUND §6.3): PD+FF fine rate(≤1kHz) 계획 추종           │
   │    u_cmd = u_ff + Kp(q_plan−q) + Kd(v_plan−v)                        │
   └───────────────────────────┬────────────────────────────────────────┘
                        τ → sim/실행 (hard 접촉, dt~2ms)
조각구현역할
① forwardstep_kkt / MuJoCo로버스트 hard 접촉(penetration-launch 없음). dt~2ms서 안정(A 컨트롤러 검증)
② λ 해석 그래디언트dyn_derivs_relaxed / dyn_derivs_kkt★논문 핵심. ∂λ/∂(q,v,u) 해석적(FD EXACT). 완화=논문판 ρD(vⁿ∘λⁿ=ρ·법선전용, RELAX_MODE=D) 또는 기본 εI(Tikhonov, vⁿ∘λⁿ=−ελ²). firm contact선 동일, make/break서 ρD가 부드럽고 물리적. ★계산법 2가지: FD(관절 44회 흔들어 차분, 195ms) vs 해석(kinematic Hessian ∂J/∂q + RNEA트릭 ∂M⁻¹/∂q 조립, 82ms=2.4×·값 exact=FD 1.66e-9). 해석=HOUND 실시간(~70μs) 방식, C++ ANALYTIC=1
③ 저수준 추종PD+FF (CTRL_DT≤1ms)MPC 계획을 fine rate로 추종. 제어 유지간격 짧아야 hard 접촉 안정
입력의 성격 — base 참조는 능동 지정 미션(전진/선회/pitch/높이·앉기·서기·눕기), 관절 참조는 nominal stance 고정(regularization). 걸음·발판·접촉 스케줄은 처방 안 함 — foot-slip cost로 online 창발. 즉 조절 실질입력 = desired 몸통 pose 하나. 다리각도 궤적이 아니라 홈 자세 하나만(자세 전환은 목표 관절각 포함).
