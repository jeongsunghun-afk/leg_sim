02_Leg 16-DOF · ocs2_02leg/ (test02legMujoco) · OCS2 centroidal NMPC + WBC

D1 — OCS2 통합 Perceptive NMPC → 02_Leg

D1은 컨트롤러가 아니라 하나의 폐루프 통합 NMPC — Grandia 2023(ANYmal 실기)식으로 base·발판·접촉력을 지형-aware 통합 최적화하고, 그 아래 WBC가 1kHz로 실현한다. TAMOLS injection(A 위에 계획만 주입)과 달리, D1은 지형 제약이 NMPC 안에 들어간 통합 폐루프다. OCS2 legged_robot을 02_Leg MuJoCo로 포팅한 우리 구현.
본 문서=D1이 무엇을 어떻게 푸나 + 문제정의 + 실증·한계. 상세 개발기록은 D1_OCS2_개발리포트.md. 같은 양식 비교=pipeline_tamols.html.

1 · 파이프라인 — 통합 NMPC + WBC 캐스케이드 A와 같은 2단 구조

TAMOLS injection이 A의 검증된 gait클럭 위에 계획을 얹는 방식이라면, D1은 OCS2 통합 NMPC 하나가 base·발판·힘을 전부 co-optimize하고 WBC가 추종하는 단일 폐루프다. 지형(SDF)은 별도 주입층이 아니라 NMPC 비용/제약 안에 들어간다.

⑤ 상위 — OCS2 centroidal NMPC (SqpMpc)

centroidal 동역학 위에서 base 궤적·접촉력·발 스윙을 하나의 OCP로 최적화. euler base(Composite(Translation+SphericalZYX), nq=nv=18). SQP-RTI + auto-diff + HPIPM.

state x ∈ R28 = [centroidal 모멘텀(6) · base pose(6) · joint q(16)]  input u ∈ R28 = [접촉력 f(12) · joint v(16)]

비용 · 제약

  • tracking: base 속도·높이 명령 추종 + nominal 관절/발 자세
  • friction cone(부등식) · zero-force @ swing · zero-velocity @ stance(접촉 유지)
  • perceptive(옵션): 발-지형 클리어런스 SDF(soft) · 발판배치 반평면(A·p+b≥0)

검증: STANCE 총수직력 373.9N≈mg 372.9N(힘균형) · TROT 대각쌍 교대(Fz→0)·전환 t=0.35 정확 · SQP ~4.5ms/iter(실시간).

⑥ 하위 — WeightedWbc (legged_control 충실 포트)

NMPC 참조를 전신 토크로. legged WbcBase+WeightedWbc 이식 — 단일 weighted QP(A의 계층 WBIC와 대비: soft-가중 단일 QP).

min ‖Abasex−bbase‖² + wsw‖swing‖² + wf‖f−fdes‖² + wpost‖posture‖²  x=[q̈(18)·f(12)·τ(12)]
hard: full-EOM [M,−Jᵀ,−Sᵀ]x=−nle · no-contact-motion · swing zero-force · τ limit · friction pyramid

표준 τ = τff + τpd (Bellicoso 2016, eq 17-19)

모션 task = r̈des(FF) + Kp·posErr + Kd·velErr − J̇u  (A의 WBIC와 동일 구성)

솔버=qpOASES 3.2(legged와 동일) 또는 eiquadprog. 널스페이스 posture task(wpost=0.5)=능동 발목 redundancy 표류 억제(A의 whip 억제와 동종).
