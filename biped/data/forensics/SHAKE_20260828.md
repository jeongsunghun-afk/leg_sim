# 2점 stand 떨림 — 원인 규명 기록 (2026-08-28 실기)

## 증상
2점 평발 stand 는 서지만 **심하게 떨리고**, 시간이 갈수록 **한 방향으로 기운다**(별개 현상).

## 계측 (arm_trace 3초 · 500 Hz · q/dq/tau 8축)

| 조건 | 주파수 | HR_calf 진폭 | HR_calf τ 진폭 0→3s |
|---|---|---|---|
| 기준 (v0=0.2 · kp floor 0.30 · 프루닝 ON) | 7.1 Hz | 2.70° | 1.05 → **3.72** Nm |
| A: `STAND_KP_FLOOR=0` | 9.3 Hz | 1.49° | 0.95 → **3.83** Nm |
| B: `LAT_COMP_MS=0` | 8.1 Hz | 3.76° | 0.94 → **3.94** Nm |

**세 조건이 사실상 동일**하고, 셋 다 3초 블렌드 동안 **단조 증가**한다.
블렌드 계수 bs 가 0→1 로 오르며 **WBIC 토크 권한이 커질수록 진동이 자란다** = 전이가 아니라 발산.

### ★2026-08-28 정정 — 위 표의 두 줄은 근거가 틀렸다

**① "25~70 Hz 대역 에너지 4% 이하" 는 사실이 아니다.**
두 독립 조사가 같은 파일에서 반증했다: 그 대역이 **HL_hip 39~50% · HR_hip 39~62%** 다
(hip 의 실피크는 15~70 Hz 이고 5~12 Hz 지분은 9.4~20.5% 뿐 — **hip 은 8 Hz 판별에 부적격**).
다만 25~70 Hz 는 ∮τ·dq 가 21/24 **음수**(소산)라 8 Hz 를 키우지는 않는다 — **별건**이다.

**② FRIC_COMP 은 배제된 적이 없다.**
`FRIC_V0` 만 0.2↔0.6 으로 훑었는데, 관절 속도진폭이 0.25~1.47 rad/s 라 **둘 다 tanh 포화**
(8/8 축)여서 판별력이 0 이었다. 포화 상태의 `JFRIC·sign(q̇)` 는 속도와 동상이라
등가 음의 감쇠 0.38~4.30 N·m·s/rad 를 공급한다(음의 감쇠의 8~39%).
⇒ **`FRIC_COMP=0` 은 한 번도 시험한 적이 없다.**

## 남은 설명 (미검증)

**WBIC 토크 권한에 비례해 발산** + **base 자세가 조작값**(IMU 전부 0 → 쿼터니언 항상 단위).
WBIC 는 가짜 수평 자세로 지면반력을 계산하므로, 권한이 커질수록 모델 오차가 그대로 커진다.
여기에 **HL_calf 유격 7°**(토크가 유격 안에서 헛돌다 충돌)가 겹치면 8 Hz 대 성장과 부합.

⇒ **IMU 복구 전에는 stand 튜닝이 무의미하다.** 가짜 자세를 먹는 제어기를 튜닝하는 셈.

## 기움(드리프트)은 별개 현상
cerr_x 2.5 cm → 5.9 cm 단조 증가(밑창 반길이 7.3 cm 의 80%), 사용자 육안으로도 실제 기울기 확인.
원인: 레벨링 태스크가 IMU 쿼터니언으로 오차를 계산하는데 그 값이 항상 0 → **기울어도 보정 명령이 안 나감**.

(실기에서 균형이 오히려 나빠졌다는 관찰). 켜려면 `WBIC_EQ_PRUNE=1`.
