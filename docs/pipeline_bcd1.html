pipeline B · C · D1 — 구조 & 입출력

02_Leg 17-DOF · OCP/NMPC 계열 제어기 3종(연구·분석) 구조와 입출력 변수
5종 대조표는 제어기 비교(A·B·C·D1·CI) · 관련 A · CI · RL
개발방향 = APT-RL. 아래 B·C·D1은 모델기반 연구/분석 제어기(전부 비실시간 또는 미구축, 지형 협조 한계). 역할은 오프라인 교사·베이스라인·청사진. 험지 본류는 RL. 상세 지형 실패근거는 모델기반 갭크로싱 리포트.

BKinodynamic OCP + TSID quad_centroidal_17dof

방식 — 센트로이달 kino-dynamic OCP(aligator ProxDDP RTI)로 base·CoM·접촉력·발판 궤적 생성 → TSID(KinodynamicsID)가 전신 토크. 지형=heightmap 발판 nudge + TAMOLS 소비자. 비실시간(~14 step/s).

[명령 v/vy/w] ─▶ ┌─ Kinodynamic OCP (ProxDDP RTI, N=50) ─┐ ─▶ [xs·us 궤적] [heightmap] ─────▶ │ + setExternalFoothold(발판 주입 훅) │ [상태 measureState]▶└──────────────────────────────────────────┘ │ 보간(Interpolator) ▼ TSID (kino_ID.solve, 접촉·마찰콘) ─▶ [τ] ─▶ 로봇
입력 — 명령CMDFILE v/vy/w만(나머지 무시) · HEIGHTMAP·HM_BASE·GAP env
입력 — 상태device.measureState()(pinocchio 규약) · 선택 heightmap(mj_ray)
핵심 파라미터FOOT_DECISION·W_FOOT_REF·MAXITER·MU_INIT·CONE·STIFF·ALIP·TDS/TSS·KP_BASE·REAR_LOCK
출력 — 토크kino_ID.solve(TSID) → τ (관절)
출력 — 발행STATE_PUB cmd · 뷰어 오버레이(cmd/actual vx)
제어율/실시간~14 step/s = 비실시간(연구·헤드리스 검증용)
지형heightmap 발판 nudge(greedy) · setExternalFoothold 훅(TAMOLS/외부 발판 주입) · 평지 falls=0, 갭 실패(base–발판 협조 없음)

CFullDynamics OCP + Riccati quad_fulldynamics

방식 — 전신 rigid-body 동역학 OCP(ProxDDP RTI) → Riccati 피드백(us[0]−K·δx) 직접 토크. 지형 플래너 없음(평지 전용). 비실시간(~6–13 Hz). 풀동역학 베이스라인.

[명령 v/vy/w·body_h·mode] ─▶ FullDynamics OCP (ProxDDP RTI) ─▶ [xs·us·K] [상태 measureState(+EST)] ──▶ │ Riccati: us[0] − K·δx ─▶ [τ] ─▶ 로봇
입력 — 명령CMDFILE v/vy/w · body_h · mode(stand_up/down)
입력 — 상태measureState + 선택 추정기(_estor, EST)
핵심 파라미터WBVX·WBVY·WBWZ·WBORI·ITERS·RIC·PREDFOOT·W_FOOT_REF·STIFF·TDS/TSS
출력 — 토크us[0] − RIC·K·δx (Riccati 피드백)
출력 — 발행STATE_PUB cmd · 오버레이 · 마커
제어율/실시간~6–13 Hz = 비실시간(연구용)
지형없음(평지 전용) — 지형 플래너 미적용

D1OCS2 NMPC + 계층 WBC legged_control · 외부·미구축

방식 — NavBotHub 계열 legged_control: OCS2 센트로이달 NMPC(~100Hz, SLQ/SQP+HPIPM, 지형=SDF 제약) + 계층 WBC(HoQp) 1kHz → AMP 데이터 → HIMLoco RL 배포. A와 같은 2단 캐스케이드, 차이는 NMPC(kino-dyn) vs 볼록 SRBD. 우리 환경 미구축(ROS/Gazebo, 공통벤치 없음).

[cmd_vel + 지형 SDF] ─▶ OCS2 NMPC (~100Hz, FullCentroidal, HPIPM) ─▶ [base·발판·힘 궤적] [상태추정 + perceptive] ─▶ │ 계층 WBC (HoQp, 1kHz) ─▶ [τ] ─▶ 로봇 ─▶ AMP→RL 배포
입력 — 명령cmd_vel + 지형(SDF/elevation)
입력 — 상태상태추정 + perceptive 지형
MPC 솔버OCS2 SLQ/SQP + HPIPM (실시간 RTI)
출력 — 토크계층 WBC(HoQp) → τ
제어율/실시간실시간(OCS2 RTI, NMPC 100Hz + WBC 1kHz)
지형Perceptive NMPC(SDF edge 제약) — 외부선 지형 파쿠르 시연(AMP→RL 배포 단계)
