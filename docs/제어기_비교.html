3포지셔닝 각 제어기의 역할

  • A 본선 배포 — 1kHz 실시간, GUI 전기능 조종. 평지·중속·선회·기립. 연속지형 반응형.
  • B 연구·TAMOLS 소비자 — 비실시간, 지형 발판 heightmap. TAMOLS 계획 검증용.
  • C 연구·풀동역학 베이스라인 — 평지 전용, 지형 플래너 없음.
  • D1 분석·청사진 — OCS2 생태계(외부). 우리 미구축. RL 배포의 실전 참조.
  • CI 종결 — 접촉창발 연구niche. 로버스트 험지 부적합 확정(음성결과=RL 방향 근거).
APT-RL 방향 — 위 모델기반들은 오프라인 교사·연속지형 배포(A)로 역할이 정리됨. 험지 크로싱 본류는 APT-RL(RL 정책이 heightmap→발판·행동, TO/모델기반은 오프라인 교사 데이터). 각 제어기 상세 구조·I/O는 개별 pipeline 문서 참조.
