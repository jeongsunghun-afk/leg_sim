# PACE 액추에이터 식별 — 실행 체크리스트 (MD80)

> **목표**: 관절별 플랜트 파라미터 `θ = {Mₐ, d, f_c, f_v, τ_sat, q̇_max, Δ}` 를 실기서 식별 →
> MuJoCo/IsaacLab actuator 모델을 실물과 정합 → 그 위에서 kp/kd 설계.
> **이유**: 로터관성·기어마찰·감쇠·토크-속도·지연이 우리 **sim2real 갭 #1**(현재 Drake/추정치).
> 관련 메모: `pace-sim2real-actuator-id`, `no-unphysical-sim2real-hacks`, `sim2real-checklist`, `02leg-motor-spec`.

## 큰 그림 (2 스테이지 + 후속)
```
①측정(가진+로깅) → ②PACE fit(CMA-ES: sim vs real) → 검증 → 모델통합 → kp/kd 설계
    ↑ 하드웨어 실험         ↑ 식별 알고리즘(본체)
```
- **kp/kd는 식별 대상이 아님** — 당신이 정하는 값. PACE는 **플랜트 θ**를 찾음.
- **실제토크(전류→τ)를 로깅하면 kp/kd가 fit식에서 사라짐** = 순환 소멸(경로 A).

## Phase 0 — 준비물 / 벤치 세팅
- [ ] MD80 + CAN/FDCAN 인터페이스 + 전원, SDK 통신 확인
- [x] `kp=0, kd=0` (raw torque) 모드 허용 확인 ✅ *(이미 확인)*
- [ ] **1축 격리** — 택1 (분해 불필요)
  - [ ] **조립 상태로 한 축씩 + 나머지 축 잠금** ← 권장 (분해 안 함)
    - 나머지 관절 고정(기계적 핀/클램프, 또는 MD80 high-kp 위치홀드) → 대상 관절만 1-DOF
    - `[M_ii(q_i)+Mₐ,i]q̈_i = τ_i − g_i(q_i) − d·q̇_i − f_c·sign − f_v·q̇_i` (나머지 q̈=q̇=0 → 커플링 소멸)
    - 부하 = 실제 하부 링크(현실적). `M_ii`는 CAD/URDF서 계산 or 함께 식별
    - 근위(Hip)는 **다리 하나를 공중에 띄우고**(base 고정·발 지면 이탈) 하면 편함
  - [ ] (대안) 벤치 분해 + 알려진 부하: 진자 암(m,l 측정) 또는 교정 플라이휠(J_load) — 가장 깨끗하나 최다 작업
- [ ] **안전장치**: 하드스톱(가동범위 제한) + E-stop (kp=kd=0은 복원력 없어 폭주 가능)
- [ ] **로깅 파이프라인**: ≥1 kHz, 동기 타임스탬프
  - [ ] `q`(엔코더), `q̇`, **`τ_actual` = Kt·I·N** (전류센싱 → 출력토크), 명령신호
- [ ] 스케일 상수 확보: 감속비 `N`, 토크상수 `Kt`, 엔코더 분해능, 데이터시트 `J_rotor`·`τ_peak`·`q̇_max`

## Phase 1 — 가진 궤적 설계 (측정 입력, kp=kd=0 · τ_ff 인가)
> 각 파라미터가 "사는 영역"을 자극해야 식별됨. 보행궤적만으론 부족.
- [ ] chirp / multisine **0.1 ~ 20 Hz**, 진폭 다양
- [ ] **저속 반전 + 속도 0 교차** 구간 → Coulomb 마찰 `f_c`
- [ ] **고속 + 고토크(포화 근처)** 구간 → 토크-속도 `τ_sat, q̇_max` *(보행이 안 밟는 유일 영역)*
- [ ] **step / 구형파** → 지연 `Δ`
- [ ] **급가감속 / 고주파** → 반사관성 `Mₐ` (가속 커야 J가 드러남)
- [ ] 넓은 `q̇` 범위 → 점성감쇠 `d`, 점성마찰 `f_v`
- [ ] **★전 가동범위(q_i 전체) 가진** → 상수 `Mₐ`와 자세의존 `M_ii(q_i)` 분리 *(한 자세만 하면 lump되어 못 나눔; 또는 CAD `M_ii` 믿고 `Mₐ=총관성−M_ii`)*
- [ ] 안전 가동범위 내, 진자면 하강 평형 주위로 진동

## Phase 2 — 데이터 수집 (관절 종류별)
- [ ] **Hip / Knee / Ankle 각각** (감속비 28/84·42/126·56/168 → 로터관성·마찰 전부 다름 → θ 별도)
- [ ] 관절별: 가진 실행 + 전 채널 로깅
- [ ] **반복 측정** (재현성/노이즈), 가능하면 warm/cold(온도) 조건
- [ ] **hold-out 궤적** 별도 수집 (검증 전용, fit에 미사용)
- [ ] 로그 저장(csv/parquet) + 동기·단위 확인

## Phase 3 — sim 벤치 모델 (PACE fit 준비)
- [ ] MuJoCo(또는 수식) **1-DOF 벤치 모델**: 부하관성 `J_load` + 중력 `m·g·l·sin(q)` + actuator(θ)
- [ ] 실험과 **똑같은 입력**(τ_ff 시계열)을 sim에 재생 가능하게 배선
- [ ] `q̈` 계산: **영위상(zero-phase) 필터 미분**을 실측·sim **동일하게** 적용

## Phase 4 — PACE fit (CMA-ES 식별) = ②본체
- [ ] **모델식** (1-DOF 그레이박스):
  ```
  (J_load + Mₐ)·q̈ = τ_actual − d·q̇ − f_c·sign(q̇) − f_v·q̇ − m·g·l·sin(q)
  ```
- [ ] **목적함수**: `minimize_θ  Σ ‖ q̈_meas − q̈_sim(θ) ‖²`  (또는 q,q̇ 궤적 오차)
  - 실제토크 로깅 시 **kp/kd 불필요**(τ_actual이 입력).
- [ ] **θ = {Mₐ, d, f_c, f_v, τ_sat, q̇_max, Δ}** (+ `J_load·m·l` 미지면 함께)
- [ ] 풀이: **CMA-ES** (또는 선형부 LSQ[J·d·f_v] + 마찰부호·지연 비선형)
- [ ] 파라미터 경계·초기값 = 데이터시트 (`Mₐ≈N²·J_rotor`, `τ_sat≈τ_peak`, `q̇_max`)
- [ ] **관절별 θ\*** 산출

## Phase 5 — 검증
- [ ] **hold-out 궤적** 예측 오차 (fit 안 쓴 데이터로 sim vs real)
- [ ] **물리 sanity**: `Mₐ ≈ N²·J_rotor`(데이터시트), `f_c/d` 합리 범위, τ-ω가 스펙 근처
- [ ] **잔차 분석**: 계통 잔차 = 미모델 항 신호(예: 위치의존 마찰, cogging)
- [ ] (선택) 보행류 궤적서 sim vs real 토크·궤적 일치 확인

## Phase 6 — sim2real 통합 (θ → 시뮬레이터)
- [ ] MuJoCo/IsaacLab actuator에 반영:
  - `armature = Mₐ` (= GEARBOX 반사관성, 현재 추정치 → 실측 교체)
  - `damping = d`, `frictionloss = f_c` (+ 점성 `f_v`)
  - DCMotor `effort_limit/saturation = τ_sat`, `velocity_limit = q̇_max` (MOTOR_CURVE)
  - 제어루프 지연 `Δ` (액추에이터 지연 모델)
- [ ] **비물리 캡 금지** — 한계는 물리 τ-ω 곡선으로만 표현(`no-unphysical-sim2real-hacks`)
- [ ] sim 재검증: 같은 가진 재생 → 실측 매치

## Phase 7 — kp/kd 설계 (식별된 플랜트 위, PACE와 독립)
- [ ] `kd ≈ 2·ζ·√( kp · (J + Mₐ)_eff )`, ζ ≈ 0.7~1 (임계감쇠 근처)
- [ ] `kp`: 대역폭 < 액추에이터/센서 대역, 지연 Δ 안정여유(위상마진) 확보
- [ ] sim서 폐루프 검증 → 하드웨어 미세재튜닝
- [ ] 배포 컨트롤러(WBIC/MPC + 관절 PD, IsaacLab `DCMotorCfg.stiffness/damping`)에 반영

## 핵심 원칙 · 함정 요약
- **kp/kd ≠ 식별 대상.** PACE는 플랜트(θ) 식별. kp/kd는 그 위에서 설계.
- **실제토크(전류) 로깅** → fit식에 kp/kd 안 들어감 = 순환 소멸. *(재구성 τ=kp(q*-q)+kd(q̇*-q̇)는 포화 전 영역만 유효 → 전류 로깅 권장)*
- **순수토크(kp=kd=0) 폭주** → 진자 부하/하드스톱으로 구속.
- **포화선(τ_sat·q̇_max)** 은 벤치서만 안전하게 고속·max토크로.
- **관절종류별 개별 식별** (감속비 다름).
- **격리(1축)** 로 커플링 제거 — 전신 동시 가진은 링크관성과 얽힘.
- 데이터시트 값은 **초기값/경계**로, 실측이 최종.
