TAMOLS 지형 계획층 — A 실행스택 위에

TAMOLS(Terrain-Aware Motion Optimization, Jenelten 2022)는 컨트롤러가 아니라 TO(계획)층 — base pose(위치·자세)+발판을 GIAC 안정제약으로 co-optimize. A 파이프라인의 ③발배치·④x_ref 자리에 끼어들어, 그 아래 MPC→WBIC 실행스택은 그대로 재사용한다.
본 문서=TAMOLS가 A 위 어디에 어떻게 붙나 + TAMOLS 문제정의 + 협조 실증·한계. 실행층(MPC/WBIC) 상세는 pipeline_a.html.

1 · 두 파이프라인 — full TAMOLS(pure-online) vs injection(TAMOLS+A)

TAMOLS를 쓰는 방식이 둘이다. A = full TAMOLS(pure-online): TAMOLS가 base·발판·자세 전부 계획하고 WBC가 직접 추종 — 현재 붕괴이나 우리 목표(진짜 지형인지 계획). B = injection: A의 실행스택 위에 TAMOLS 계획만 주입 — 작동(마진 얇음), 현재 우회책.

A · full TAMOLS (pure-online)  ❌ 현재 붕괴 · ★목표

TAMOLS 2 · 솔버가 푸는 문제 — TO (base+발판 co-optimize)

base pose 스플라인과 발판을 함께 최적화하고, 접촉력 없이 GIAC(Gravito-Inertial Acceleration Cone)로 안정 보장 — SRBD/ZMP의 일반화(비평면 지원). SQP-RTI + 해석 Jacobian, self-contained cold-start(elastic globalization).

결정변수

a[phase] ∈ R6×4 = base pose 스플라인 계수 [x,y,z,roll,pitch,yaw] × 4-poly / phase  nz = 24·P + 12 + P
p ∈ R4×3 = 발판 위치(4발 착지 xy·z)   ε ∈ RP = GIAC slack

비용 (핵심)

task내용가중
foothold on ground10·(h(p.xy) − p.z)  지형높이 매칭10⁴
nominal kinematics‖pB + RB·hip − pi − ldes‖²  발=명목 stanceT
base pose alignmenttorso를 지형 평면(stance fit)에 정렬100·Tk
edge avoidance∇h·∇h — 엣지 회피(미끄럼 방지)3
tracking‖PB − PB,des‖² 모멘텀2·Tk

제약

  • GIAC 안정(부등식): 중력-관성 가속도가 지지폴리곤 콘 내(접촉력 free 안정성)
  • base bounds: z∈[zlo,zhi] · roll/pitch/yaw 한계 · 위상 연속(pos·vel junction)
  • 발판: foot_y 대칭 box · gap 회피(앞발 갭너머·뒷발 갭앞)

솔버: solve_fast(SQP-RTI·GN·QuadProg++·elastic). GIAC 행=블록-sparse FD, 나머지 해석. 출력: 계획 base pose 궤적 + 발판 → A의 ③′④′로 주입.
