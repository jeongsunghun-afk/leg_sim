## 1. 배포급 제어기 (본선)
- **A 제어기** — 17-DOF convex MPC(Di Carlo SRBD) + WBIC(Kim) + Raibert/capture. **C++ 1kHz 실시간(~5×)**.
  walk 0.6 / trot 1.4~1.75 / run 2.0 m/s falls=0 · 자동차식 허리조향(Ackermann) · 자세(서기/앉기/눕기/기립·점프) · push recovery.
  → [RUN.md](RUN.md) · [pipeline_a.html](pipeline_a.html) · [params_a.html](params_a.html)
- **주행선회 근본해결**(MPC euler-rate 프레임 수정) · **뒤 thigh 폭주 해결**(raibert 0.5 중립점) · **발판-발끝 정합** 등 근본원인 다수 규명.

## 2. D1 — OCS2 통합 perceptive NMPC (조건부 배포)
- OCS2(SQP·HPIPM) 포팅: 지형 SDF·발판배치(convex region)·지형적응 base. 경사 8~15° 등반 falls=0.
- **C++ 배포골격**(`ocs2_02leg/deploy/` — 제어를 MuJoCo서 분리, HAL 경계 검증) · D1 전용 GUI(trot/walk/bound 라이브 전환).
- 근본버그 해결: GUI 참조 이중계산(등반붕괴)·발판 마커=MPC 계획 발(70→6mm 정합)·heightmap 시각화.
  → [D1_OCS2_개발리포트.md](D1_OCS2_개발리포트.md) · [pipeline_d1.html](pipeline_d1.html)
