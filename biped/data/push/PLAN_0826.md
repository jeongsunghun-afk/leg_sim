# push 실험 계획 — 4원 연립으로 경로 확정 (2026-08-25 저녁 재설계)

★재설계 이유(08-25 실측): **발끝밀기는 두 점 접촉이 유지되지 않는다** — 힘을 발끝
자코비안으로 걸면 정역학상 뒤꿈치 힘이 0 이라, 손실 잔차가 발목을 돌려 뒤꿈치를
띄운다(② 시도에서 +6→+22 mm, 발목 −60→−53.5°). 심으로는 못 잡는다. 그래서
"전체접촉 스윕"을 폐기하고 **뒤꿈치밀기(PUSH_POINT=heel)** 와 **Qhome8 발끝밀기**
로 대체한다.

## 연립 구조 — 미지수 r = (hip, thigh, calf, foot) 경로 전달비

```
  E1 (0° toe, 확보 ✓):     0.25·hip + 0.72·calf              = 0.82
  E2 (평발 toe=③, HL ✓):   0.20·hip + 0.30·thigh + 0.50·foot = 0.783
  E3 (평발 heel, 신규):     0.47·hip + 0.53·calf              → E1 과 연립, hip/calf 분리
  E4 (Qhome8 toe, 신규):    0.48·hip + 0.24·thigh + 0.28·foot → E2 와 연립, thigh/foot 분리
                            (thigh:foot 비 0.86 vs E2 의 0.60)
```

가중은 매 스윕 기록된 q 로 노트북에서 재계산한다(위 숫자는 설계용 근사).

⚠ 공통: 로봇 고정 · GUI 끄고 push_scale 실행 · 기입은 "저울 5초 ±10 g 안정" ·
유격은 심으로 저울을 올려 100~300 g 창 · 각 스윕 후 JSON 커밋·푸시
(`git pull --rebase && git push` 패턴).

## 순서 A — ③ HR: 평발 발끝만 (HL 은 08-25 완료, blend 0.783)

```
  ./run_deploy_hw.sh flat
  python3 tools/push_scale.py --leg HR --max 30 --step 5
  저울: 발끝만 올라가게(뒤꿈치는 모서리 밖 허공·발은 수평 그대로)
```

## 순서 B — ② 재설계: 평발 뒤꿈치밀기 (E3) — ★재빌드 후

```
  배포기 Ctrl+C → PUSH_POINT=heel ./run_deploy_hw.sh flat
  python3 tools/push_scale.py --leg HL --max 30 --step 5
  python3 tools/push_scale.py --leg HR --max 30 --step 5
  저울: 발바닥 전체가 저울 위면 됨(뒤꿈치 심 불필요 — 접촉이 뒤꿈치로 자기수렴)
  PUSH_DBG 배너에 "다리 HL·뒤꿈치" 로 표기되는지 확인
```

예측: α공통이든 축별이든 **0.83** (hip·calf 만 실림) — 0.83 에서 벗어나면
hip/calf 배분이 종전 해석과 다르다는 새 정보다.

## 순서 C — ④ Qhome8 발끝밀기 (E4) — thigh/foot 최종 분리

```
  yaml home = Qhome8 원복됨(이 커밋) — 1점 모드가 이걸 읽는다
  배포기 Ctrl+C → ./run_deploy_hw.sh        (1점·발끝밀기 기본)
  python3 tools/push_scale.py --leg HL --max 30 --step 5
  python3 tools/push_scale.py --leg HR --max 30 --step 5
  ⚠Qhome8 발끝은 0° 때보다 **64 mm 낮다** — home 도달 후 저울을 놓을 때 심을
    그만큼 빼라(도구가 "저울 배치 → 엔터" 흐름이라 이동 중 충돌은 없음)
```

## 각도 시험(구 ①) — 커플링 상쇄로 사실상 완료

calf jog 때 foot 이 안 움직임(08-25 실측) = calf·foot 각도배율 비가 설계값과 정합.
잔여 확인 1개: calf 20° 명령 → 정강이 물리 20° (수평계 한 번, 절대 크기 확정).
