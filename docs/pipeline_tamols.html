TAMOLS 파이프라인 — 계획·추종·협조·한계

Terrain-Aware Motion Optimization for Legged Systems (Jenelten 2022, ETH). 02_Leg 17-DOF 적용 · 2026-07-29
TAMOLS = TO(계획)층 — base pose(위치·자세) + 발판을 GIAC 안정제약으로 co-optimize. 솔버 완성(solve_fast SQP-RTI·해석Jacobian <20ms·Drake 정합). ★이번 세션 = 추종 통합 + base-발판 협조 실증: injection에 TAMOLS base z 주입 → 지형 tilt 25°→1.2°. 단 injection은 짜깁기(stitched)라 마진 얇음(뷰어 "불안불안"). 강건 = 통합 폐루프 NMPC(D1/OCS2 포팅) 또는 RL(DTC).

1TAMOLS = 무엇을 계획하나

결정변수내용
base pose 스플라인6-DOF [x,y,z,roll,pitch,yaw] × 4-poly 계수 / phase. 위치·높이·자세 전부 최적화
발판 p (4×3)각 발 착지 위치. 지형 높이매칭 cost(h(p.xy)−p.z) + edge 회피
GIAC 안정Gravito-Inertial Acceleration Cone — 접촉력 없이 안정성 보장(SRBD·ZMP 일반화, 비평면 지원)
핵심: base와 발판을 함께 최적화(협조)하고 GIAC로 안정 보장. A(Raibert 발배치·SRBD)가 못하는 base-발판 협조·자세계획이 TAMOLS의 값어치. 계획층이지 컨트롤러 아님 — 추종기와 짝지어야 로봇이 움직임.

2솔버 (완성)

요소상태
solve_fast완성 SQP-RTI + 해석 Jacobian, <20ms. self-contained cold-start(elastic globalization). Drake 정합(1e-10).
online_replan완성 receding-horizon(warm-start). walk/trot gait, 지형 heightmap 주입(mj_ray).
C++ 포팅완성 tamols/ (tamols_jac·tamols_qp·tamols_online, eiquadprog).

3추종 구조 — 3가지 시도

계획(TAMOLS) ──→ [추종기] ──→ 로봇 ① injection : A 연속 gait클럭 + TAMOLS 발판·base 주입 ← 연속보행 robust (짜깁기) ② 3층 : TAMOLS → SRBD MPC(GRF) → WBIC(토크) ← offline 협조추종 OK ③ 2층 : TAMOLS → WBC(GRF+토크 통합) ← z침하(QP 힘품질)

4★이번 세션 성과 — base-발판 협조 실증 (TAM_BASE)

5한계 — injection의 얇은 마진 (RL 필요성)

한계내용
