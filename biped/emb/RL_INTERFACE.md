# biped 실기 사양 — RL 학습팀 인계 문서

**작성 2026-08-10.** 이 문서가 필요한 이유는 하나다:
**MJCF 모델만 넘기면 학습된 정책이 실기에서 동작하지 않는다.**
MJCF 는 4관절을 독립으로 모델링하지만 실기는 그렇지 않고, 드라이버가 각도를 잘못 보고하며,
관절한계도 MJCF 와 다르다. 아래는 그 차이의 전부다.

값의 출처를 셋으로 구분해 표기했다 — **[실측]** 실기에서 확인 · **[계산]** 다른 값에서 유도 ·
**[미확정]** 아직 근거 없음. RL 은 [미확정] 항목을 **도메인 랜덤화 대상**으로 잡는 게 안전하다.

## 1. 좌표계 — 세 가지 각도를 구분해야 한다

| 이름 | 정의 | 어디서 쓰나 |
|---|---|---|
| **채널각** (= 모터각, 보고각) | 드라이버가 SHM 으로 보고/수신하는 값 [deg] | SHM 경계에서만 |
| **raw** | 채널각에서 부호·감속비·영점을 뺀 값. **커플링은 아직 안 풀린 상태** | 내부 중간값 |
| **모델각** | MJCF `qpos` 와 같은 관절각 [deg] | 정책·보상·관측·뷰어 **전부** |

정책은 **모델각만** 본다. 채널각은 하드웨어 경계에서 한 번만 변환한다.

### 변환 전체 (읽기: 엔코더 → 정책 관측)

```
raw_i      = (채널각_i − offset_i) / (sign_i · k_i)
모델각_i   = raw_i − coef_i · 모델각_(src_i)          # 커플링 있는 축만
```

### 변환 전체 (쓰기: 정책 출력 → 모터 명령)

```
raw_i      = 모델각_i + coef_i · 모델각_(src_i)        # 커플링 되먹임
채널각_i   = clip( raw_i · sign_i · k_i + offset_i,  −180, +180 )
```

속도는 위치와 같은 선형관계(상수항 `offset` 만 빠짐).
**토크만 다르다** — `k` 로 나누고, 커플링이 **전치(transpose)** 로 들어간다:

```
τ_ch_i     = sign_i · τ_raw_i / k_i
τ_raw_src −= coef · τ_joint_dst        # 소스축(calf)이 목적축(foot) 토크를 떠안는다
```

일률 보존에서 나온다: `q_true=(I−C)q_raw` 이면 `τ_raw=(I−C)ᵀτ_true`.
각도처럼 목적축에 더하면 **틀린다** — 방향이 반대다.

구현 원본: [`emb/interface/joint_map.py`](interface/joint_map.py) ·
C++ 미러 [`cpp/src/deploy_hw.hpp`](../cpp/src/deploy_hw.hpp) (두 구현은 패리티 검증됨, 최대차 3e−6).

## 2. ★기구 커플링 — MJCF 에 없는 가장 큰 차이

**calf(무릎)를 움직이면 foot(발목)이 종속적으로 따라 움직인다.** 발목이 링키지로 구동된다.

```
모델각_foot = raw_foot − coef · 모델각_calf
raw_foot    = 모델각_foot + coef · 모델각_calf
coef = +1     (HL_foot ← HL_calf,  HR_foot ← HR_calf)
```

### 반드시 짚어야 할 세 가지

**(a) coef 는 감속비 *이후*(관절각) 공간의 계수다** — 모터각 공간이 아니다. **[실측]**
> "calf 관절이 30° 돌면 foot 관절도 30° 돈다"

감속비가 다르므로(calf 10.5:1, foot 8.4:1) **모터각 비율은 1:1 이 아니다**:
`k_foot/k_calf = 1.2/1.5 = 0.8`. 실제로 calf 관절 +30° 명령 시 채널각은 calf ∓45°, foot ±36° 로 나간다.
모터각 공간으로 착각해 넣으면 30° vs 24° 로 어긋난다.

**(b) 부호를 틀리면 상쇄가 아니라 가중된다** — `coef = −1` 로 넣었을 때 발목이 무릎을 **더** 따라갔다. **[실측]**

**(c) 이 계수는 서보가 물린 상태에서 측정할 수 없다.**
JOG 중 엔코더 회귀는 발목 모터가 **우리 보상 명령을 추종**하므로 자기 명령을 되재는 것이 된다
(R²=0.998 짜리 깨끗한 회귀가 나오지만 무의미하다 — 실제로 이 함정에 빠져 부호를 반대로 판정했었다).
기구를 재려면 **off(무여자) 상태에서 무릎을 손으로 돌려야** 한다 →
[`emb/diag/couple_check.py`](diag/couple_check.py).

### RL 이 취할 선택지

| 방법 | 내용 | 비고 |
|---|---|---|
| **A. MJCF 에 커플링 반영** | `<equality joint1=foot joint2=calf polycoef="0 -1 0 0 0"/>` 로 구속 | 시뮬 자체가 실기와 같아짐. 권장 |
| **B. 래퍼에서 변환** | MJCF 는 독립으로 두고 action/obs 래퍼에서 위 식 적용 | 학습은 독립 관절로, 배포만 변환 |

**A 를 쓰면 동역학까지 맞고, B 를 쓰면 기구학만 맞는다.** 발목 관성이 무릎 토크에 실리는 효과는
B 로는 재현되지 않는다. 정책이 토크를 다룬다면 A 를 권한다.

- **sign** [실측] — 모터 + 방향이 모델좌표의 어느 쪽인가. 8축 전부 조립 후 육안 검증.
  hip 만 좌우 같고(−1/−1) thigh·calf 는 좌우 반대, foot 은 좌우 같다(−1/+1 아님, 실측 결과).
- **offset** [실측] — **채널각 단위**다(`sign·k` 로 나누기 **전에** 뺀다). 기준자세에서 채취.
- **gear_k** [계산+실측] — 드라이버 감속비 오설정 보정. 아래 §4.
- **kp/kd** — 드라이버 MIT 임피던스 게인. **단위가 rad 기준**이다: `τ = kp·(q_des−q)[rad] + kd·(dq_des−dq)[rad/s]`.
  명령·상태는 deg 인데 게인은 rad 라 `kp 1 ≈ 0.0175 Nm/deg`. [실측: 예측 0.775 Nm vs 실측 0.757 Nm, 오차 2%]

### 기준자세와 홈

```
calib.ref_joint_deg = [0, 35, −60, 60, 0, 35, −60, 60]   # 영점을 잡은 물리 자세
home.q_deg          = [0, 35, −60,  0, 0, 35, −60,  0]   # HOME 버튼 목표
```

`thigh = +35°` 는 MJCF 기하와 정합한다 — MJCF 에서 thigh 0° 는 이미 35° 앞으로 기운 자세이고
(`HL_calf_link pos="0.13192 0 -0.1884"` → `atan(0.13192/0.1884) = 35.0°`), 대퇴가 연직 아래를
향하는 각이 정확히 +35° 다. **[계산, MJCF 기하에서 독립 확인]**

## 4. 드라이버 감속비 오설정 — 각도 배율이 축마다 다르다

드라이버가 **전 축을 7:1 로 가정**해 관절각을 보고한다. 실제 감속비는 hip/thigh 7 · calf 10.5 · foot 8.4.

```
보고각 = 실제 관절각 × (실제감속비 / 7)      →  gear_k = 실제감속비/7
gear_k: hip 1.0 · thigh 1.0 · calf 1.5 · foot 1.2
```

**[실측]** `gear_k` 적용 후 뷰어와 실기의 회전비율이 일치함을 확인.
이 관찰은 **링키지 가설을 배제한다** — 4절 링키지라면 배율이 자세마다 변해 **상수** `k` 로는
전 구간이 맞을 수 없다. 상수 하나로 맞았다는 것이 "드라이버가 고정 7:1 로 나눈다"의 서명이다.

### RL 이 알아야 할 파급

**게인이 설계보다 세게 걸린다.** 드라이버는 채널각 오차에 kp 를 곱하는데,
채널오차 = 배율×관절오차이고 실제토크 = 보고토크×배율이므로

```
실제 관절강성 = kp × k²
calf 50 → 실효 112.5 (2.25배)   ·   foot 30 → 43.2 (1.44배)
감쇠비도 ζ×k 로 변한다: calf 0.76→1.13(과감쇠) · foot 0.82→0.97
```

⚠**드라이버가 고쳐지면 calf·foot 이 갑자기 약해진다.** RL 정책이 이 강성에 의존해 학습됐다면
그때 재학습이 필요하다. 그 전까지는 `gear_k` 를 그대로 두는 게 실기와 일치한다.

**토크 임계의 의미도 축마다 다르다.** `safety.tau_trip_nm` 은 **보고토크** 기준이라
설정 15 Nm 이 calf 는 실제 22.5 Nm, foot 은 18 Nm 이다. **[미해결 — 균일화 안 함]**

## 5. 한계는 **박스가 아니다**

커플링 때문에 `(calf, foot)` 의 허용 영역이 직사각형이 아니다. 세 층이 있다:

1. **관절한계** `min/max_deg` — 모델각 공간, 축별 독립. 위 표.
2. **모터각 제약** — 물리 제약은 발목 **모터각**(`raw = foot + coef·calf`)에 걸린다.
   foot 단독으로 좁히면 무릎이 펴져 있을 때 쓸 범위까지 잘린다.
3. **★±180 래핑** — Emb 는 초과분을 클램프가 아니라 **래핑한다**
   (`halGait.cpp:666-671`, `while(fPosition>180) fPosition-=360`).
   181° 를 보내면 −179° 로 뒤집혀 **반대편으로 날아간다.**
   ⇒ 우리 코드가 `q_joint_to_ch` 에서 ±180 으로 **포화**시켜 막는다.
   현재 관절한계 끝단에서 최대 |ch|: HR_thigh 169.4 · HR_calf 174.7 · foot 180.0(극단 조합에서만).

**RL 이 액션 범위를 정할 때** 1번(관절한계)만 보면 안 되고, 2·3 을 위반하는 조합은
포화되어 **명령이 조용히 왜곡된다**. 포화 횟수는 `JointMap.n_saturated` 로 노출돼 있다.

## 6. MJCF ↔ 실기 불일치 목록 (전이 실패의 후보)

| # | 항목 | MJCF | 실기 | 대응 |
|---|---|---|---|---|
| 1 | **calf→foot 커플링** | 없음(독립 4관절) | coef +1 | equality 추가 or 래퍼 |
| 2 | calf 하한 | −54.9° | **−62°** (구조적 한계 −60 실측) | config 가 넓힘 |
| 3 | foot 상한 | +40.0° | **+62°** (실측 +60) | config 가 넓힘 |
| 4 | 각도 배율 | 1:1 | calf 1.5 · foot 1.2 | `gear_k` |
| 5 | base | free joint | **현재 공중 매달림** | 학습 시 base 고정 여부 결정 필요 |

2·3 은 **MJCF 도 갱신해야 한다** — 지금은 config 만 넓혀 둔 상태라 시뮬이 실기보다 좁다.
정책이 시뮬 한계에 붙어 학습되면 실기에서 쓸 수 있는 범위를 못 쓴다. **[미해결]**

- **관측**: `/tmp/biped_state.json` — `q_leg_deg`(모델각, 커플링 풀린 값) ·
  `q_ch_deg`(raw 채널각, 캘리브레이션용) · `rpy_deg`(IMU, 현재 0) · `health`/`installed` · `loop_hz`
- **명령**: `/tmp/biped_cmd.json` — `mode` · `jog_deg`(모델각) · `v`/`vy`/`w` · `body_h` · `contact` · `seq`

  **토크 제어는 `write_torque(q_rad, dq_rad, tau_nm, kp=0, kd=0)`** — RL 이 붙을 가능성이 가장 높은 지점.
- 파일 기반 IPC 는 ~50Hz 폴링이다. 고주파 정책이면 SHM 에 직접 붙는 편이 낫다.

## 8. 미확정 — 도메인 랜덤화 후보

| 항목 | 현재값 | 불확실성 |
|---|---|---|
| `coef` 크기 | 1.0 | 부호는 [실측], **크기는 미실측**. 5% 오차면 47° 스윙에 2.5° 잔차 |
| `gear_k` 정밀도 | 1.5 / 1.2 | 감속비에서 유도. 각도기 실측 미실시 — 소수점 아래 미확정 |
| hip·thigh 관절한계 | MJCF 유래 | **물리 하드스톱과 대조된 적 없음**(calf·foot 만 실측) |
| `ROTOR_I` | 7.4e−4 | hip 실측 기반, 나머지 축은 동일 모터 가정 |
| 마찰 `JFRIC` | 0.38 | 실측이나 자세·온도 의존성 미검토 |

**한 번의 측정으로 `coef` 와 `gear_k` 를 분리할 수 없다** — 실효비가 0.947 로 나왔는데
커플링 계수가 0.947 인지 `gear_k` 가 5% 틀린 건지 구분되지 않는다.
calf 감속비를 각도기로 독립 측정해야 갈린다.
